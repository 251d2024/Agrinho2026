# Agro Forte - Futuro Sustentável

Projeto desenvolvido para o Concurso Agrinho 2026.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Objetivo

O projeto busca conscientizar sobre a importância do equilíbrio entre produção agrícola e preservação ambiental.

## Funcionalidades

- Site responsivo
- Modo escuro
- Interatividade com JavaScript
- Layout moderno
